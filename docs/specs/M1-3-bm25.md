# M1-3: BM25 first stage

## Goal

A `bm25` first stage that scores the documents' own words, with no model at all. It is the
design's default first stage for ColBERT models (`bm25 > maxsim@100`), and on SciFact it is the
best first stage before MaxSim (0.7086). After this checkpoint `Index.create(..., bm25=True)`
builds it from the documents' text, and `bm25` and `bm25 > maxsim@100` reproduce smve-lab.
It is the first stage whose stored data depends on the whole corpus (IDF, average length), so
it fixes how such data is stored before segments arrive in 0.2.

## Out of scope

- Multi-segment indexes: still 0.2. The format stores only per-segment raw counts, so 0.2 can
  add up document frequencies and lengths across segments without rewriting old segments.
- Skipped: other tokenizers (Unicode words, no stemming, other languages). Add when non-English
  documents matter; the manifest records `"tokenizer"` so a second one stays readable.
- Skipped: choosing `k1` and `b` per index or per search. Add with stage parameters in pipeline
  strings when `tune` (M2) needs them. The manifest records both.
- Skipped: computing weights per touched posting at query time (instead of once at `open`).
  Add when open time or RAM for a large corpus asks for it (see `# ponytail` in Decisions).
- Skipped: a comparison test against bm25s (design §10). The SciFact golden test pins the same
  formula; add when we claim bm25s parity.
- NFCorpus and ArguAna golden tests: a later M1 checkpoint, as in M1-2.

```python
# components/bm25.py (new)
K1, B = 1.2, 0.75
TOKENIZER = "ascii-snowball-en"


def tokenize(text: str) -> list[str]:
    """Lowercase, words = [a-z0-9]+, drop ENGLISH_STOP_WORDS, Snowball English stem (PyStemmer)."""


class BM25Stage:
    def __init__(
        self,
        terms: list[str],
        indptr: np.ndarray,
        rows: np.ndarray,
        tf: np.ndarray,
        n_docs: int,
        k1: float = K1,
        b: float = B,
    ):
        """terms: sorted, unique; term i's postings are [indptr[i], indptr[i+1]) of rows/tf.

        Computes df, document lengths (bincount of tf by row) and the float32 BM25 weight of every
        posting once. ValueError for inconsistent arrays, unsorted or duplicate terms,
        a row >= n_docs, tf < 1, or no words at all (average length 0).
        """

    @staticmethod
    def arrays(
        texts: Sequence[str],
    ) -> dict[str, np.ndarray]: ...  # one text per document -> the segment arrays below

    @classmethod
    def from_segment(
        cls, seg: Segment, cfg: dict, n_docs: int
    ) -> BM25Stage: ...  # ValueError: vocab != cfg["vocab"], unknown tokenizer, non-finite k1/b

    def scores(self, q: Encoded) -> np.ndarray:
        """(n_docs,) float32: sum over query words t of count(t in q) * weight(t, d).

        Query words not in the corpus vocabulary are dropped (they match nothing).
        ValueError if q.text is None.
        """

    def search(self, q: Encoded, k: int) -> Candidates: ...


# orchestration/index.py
class Index:
    @classmethod
    def create(
        cls,
        path,
        docs,
        tokens,
        *,
        encoder,
        dense=None,
        lexical=None,
        bm25: bool = False,
        pipeline: str = "dense > maxsim@100",
    ) -> Index: ...

    # bm25=True -> stage "bm25" from each doc's title + "\n" + text (None counts as "")
```

```text
weight(t, d) = idf(t) * tf * (k1 + 1) / (tf + k1 * (1 - b + b * len(d) / avg_len))
idf(t)       = ln(1 + (N - df(t) + 0.5) / (df(t) + 0.5))           (smve-lab's bm25.py)

manifest.json stage:
  "bm25": {"type": "bm25", "tokenizer": "ascii-snowball-en", "k1": 1.2, "b": 0.75, "vocab": V}
seg-000001/bm25/terms.npy    (bytes,) uint8: the sorted terms, UTF-8, joined by "\n"
seg-000001/bm25/indptr.npy   (V + 1,) int64
seg-000001/bm25/rows.npy     (nnz,) int32, ascending within a term
seg-000001/bm25/tf.npy       (nnz,) int32, raw term counts >= 1

scripts/export_golden_texts.py   run once inside smve-lab's environment; writes
  $LATERANK_GOLDEN_DIR/scifact_bgem3/{docs,queries}_texts.json  (list[str], aligned with *_ids.json)
```

## Decisions

| decision | why | differs from design doc? |
|---|---|---|
| Store raw term counts (`tf`) as postings; df, lengths, N and avg length are derived at `open` | design §6: IDF depends on the whole corpus, so nothing corpus-wide is frozen into a segment | no |
| No `doc_len` array: lengths = `bincount(rows, tf)` | it is fully determined by the postings; one array and one consistency check fewer | no |
| Weights follow smve-lab's arithmetic: idf in float64 cast to float32, avg_len = float32(int total / N), the rest in float32 in the same order | researcher: this reproduces smve-lab's weights bit for bit on SciFact (and the integer total stays exact past 16.7M tokens, where a float32 mean drifts) | no |
| Same per-segment, raw-count layout as Lucene and Tantivy (they add N, df and total length over segments at search time); bm25s stores finished weights and can't add documents | researcher report, 2026-10-11 | no |
| `# ponytail:` weights are computed for every posting once at `open` (float32, in RAM), then scored with the existing `score_postings` kernel | reuses the tested kernel unchanged; SciFact ~4 MB, milliseconds. Ceiling: O(nnz) RAM and open time; upgrade: weight only the touched postings per query | no |
| Terms stored sorted, joined by `"\n"` in one uint8 array; `open` builds a `{term: id}` dict | `.npy` only, no pickle, no fixed-width string waste; sorted ids don't depend on document order and make 0.2's merge simple. Terms can't contain `"\n"` | no |
| Tokenizer = smve-lab's exactly (ASCII regex, sklearn stopwords, PyStemmer English), named `ascii-snowball-en` | the golden numbers depend on it; PyStemmer is already a core dependency | no |
| Copy sklearn's 318 stopwords into `components/stopwords.py` (BSD-3 notice in the header) | avoids a scikit-learn dependency for one frozenset | no |
| The query's raw text travels in `Encoded.text` | BM25 tokenizes the text itself; M1-6 encoders will fill it | adds a field |
| `bm25` is built only when `Index.create(bm25=True)` | existing callers get the same index as before; presets (M1-6) turn it on for ColBERT. Owner OK | no |
| Unknown query words are dropped, not an error | the vocabulary comes from the corpus, so unseen words are normal (unlike BGE-M3 term ids) | no |
| Golden texts come from smve-lab's own `load_texts`, exported once to the golden folder | the exact strings smve-lab tokenized; laterank needs no `datasets`/`pyarrow`. Owner OK to add the two files to smve-lab's artifacts | no |

## Acceptance tests

- [x] AT1: `tokenize` lowercases, splits on non-`[a-z0-9]`, drops stopwords and stems
  (`"The Proteins, running!"` -> `["protein", "run"]`). A pinned list of ~20 stems fails if a
  PyStemmer upgrade changes English stemming. `ENGLISH_STOP_WORDS` has 318 words and matches
  sklearn's (SHA-256 of the sorted, newline-joined list pinned).
- [x] AT2: `BM25Stage.scores` equals a naive Python loop over the formula above (rtol 1e-5) on a
  small corpus with an empty document, a repeated query word and an unknown query word.
  `search` breaks ties by lower row. `q.text=None` raises `ValueError`.
- [x] AT3: `BM25Stage` raises `ValueError` for unsorted or duplicate terms, a row >= n_docs,
  tf < 1, mismatched lengths, and an all-empty corpus. `Encoded(text=3)` raises `ValueError`.
- [x] AT4: `Index.create(bm25=True)` writes the manifest stage and four arrays above; `search`
  with `bm25` and `bm25 > maxsim@20` equals `Pipeline.run` on the in-memory stages. Without
  `bm25=True` there is no `bm25` stage. `Index.open` raises `IndexFormatError` for a wrong
  vocab count, an unknown tokenizer, and a NaN `k1`.
- [x] AT5: golden SciFact, ±0.002 (`results/cross_dataset/summary.md`), nDCG@10 / Recall@100:
  `bm25` 0.6896 / 0.9249, `bm25 > maxsim@100` 0.7086 / 0.9249.
- [ ] AT6: `uv run pytest -q` and `uv run ruff check .` pass on all three CI operating systems.
- [x] AT7: the reviewer agent's verdict is `merge`.
